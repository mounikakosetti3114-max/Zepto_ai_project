# Zepto Data & AI Platform

This project contains three modules developed for the Zepto Data & AI Platform.

## Modules

### 1. Data Pipeline
- Data collection
- Data cleaning
- Data processing
- Data preparation

Folder:
`data_pipeline/`

### 2. Analytics Pipeline
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Machine Learning
- Model evaluation
- Random Forest
- Logistic Regression
- Decision Tree
- Fare prediction

Folder:
`analytics/`

### 3. Support Assistant
- AI-based support assistant
- Retrieval system
- Model integration
- Configuration

Folder:
`support_assistant/`

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Git & GitHub
